Morris SDK

Maven-репозиторий. Рекламный SDK для Android — rewarded и interstitial.

// settings.gradle.kts
dependencyResolutionManagement {
    repositories {
        google()
        mavenCentral()
        maven { url = uri("https://hov-aleqs.github.io/morris-sdk/maven") }
    }
}

// build.gradle.kts приложения
implementation("io.github.hov-aleqs:morris-ads:1.0.0")

Media3 и OkHttp подтянутся сами — они объявлены в POM.

Исходники и документация: github.com/hov-aleqs/morris-sdk

Закрытое программное обеспечение. Использование — по отдельному соглашению.
