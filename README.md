# Morris Ads SDK

Рекламный SDK для Android: видео с вознаграждением (rewarded) и межстраничное
видео (interstitial).

| | |
|---|---|
| Платформа | Android 5.0 (API 21) и выше |
| Языки | Kotlin, Java, C# (Unity 2021.3+) |
| Размер | ~136 КБ, плюс media3 и OkHttp |
| Сторонние измерители | не используются |

---

## Установка

```kotlin
// settings.gradle.kts
dependencyResolutionManagement {
    repositories {
        google()
        mavenCentral()
        maven { url = uri("https://hov-aleqs.github.io/morris-sdk/maven") }
    }
}

// build.gradle.kts приложения
dependencies {
    implementation("io.github.hov-aleqs:morris-ads:1.0.0")
}
```

Media3 и OkHttp подтянутся автоматически. Правила обфускации входят в состав
SDK — добавлять ничего не нужно.

## Инициализация

Один раз при старте приложения:

```kotlin
MorrisAds.initialize(context, "https://<адрес сервера>/api/ad")
```

Адрес сервера выдаётся при подключении. SDK обращается только по нему.

## Реклама с вознаграждением

```kotlin
val ad = MorrisRewardedAd(context, "rewarded_main")

ad.listener = object : MorrisRewardedAd.Listener {
    override fun onLoaded(ad: MorrisRewardedAd) {
        ad.show(activity)
    }

    override fun onLoadFailed(ad: MorrisRewardedAd, error: AdError) {
        // AdError.NoFill — рекламы сейчас нет. Это обычный исход, не сбой.
    }

    override fun onRewarded(ad: MorrisRewardedAd, reward: Reward) {
        grantCoins(reward.amount)
    }

    override fun onDismissed(ad: MorrisRewardedAd) {
        ad.destroy()
    }
}

ad.load()
```

Реализовывать нужно только те методы, которые интересны приложению —
у остальных есть реализация по умолчанию. Это работает и в Java.

## Межстраничная реклама

`MorrisInterstitialAd` устроен так же, но без вознаграждения: за досмотр ничего
не выдаётся, поэтому и события о награде нет.

## Правила, о которых стоит знать

**Все события приходят на главном потоке.** Из обработчиков можно свободно
обращаться к интерфейсу.

**Одно объявление — один показ.** После показа нужен новый `load()`.

**У объявления есть срок годности.** Загруженное и не показанное объявление
устаревает (обычно через 30 минут). Проверить готовность: `ad.isReady`.

**`destroy()` обязателен**, когда объявление больше не нужно. После него события
не приходят.

**Ролик скачивается заранее.** К моменту `show()` файл уже на диске, поэтому
показ начинается сразу, а не с буферизации.

**Реклама не закрывается раньше времени.** Кнопка «назад» до появления пропуска
игнорируется — иначе вознаграждение доставалось бы за одно нажатие.

**Звук уступает системе.** При входящем звонке показ встаёт на паузу и
продолжается после разговора.

## События

| Событие | Когда |
|---|---|
| `onLoaded` | объявление получено и готово к показу |
| `onLoadFailed` | рекламы нет или запрос не удался |
| `onShown` | картинка пошла, показ засчитан |
| `onShowFailed` | показать не удалось, вознаграждение не выдаётся |
| `onClicked` | пользователь нажал кнопку действия |
| `onRewarded` | досмотрено до конца, только у rewarded |
| `onDismissed` | экран закрыт — и после досмотра, и после пропуска |

## Ошибки загрузки

Разбирать следует по типу, а не по тексту сообщения:

| Тип | Что произошло |
|---|---|
| `AdError.NoFill` | рекламы сейчас нет. Обычный исход, не ошибка |
| `AdError.Network` | сеть недоступна или запрос не уложился в таймаут |
| `AdError.Server` | сервер ответил не 2xx, код в `error.code` |
| `AdError.Malformed` | ответ пришёл, но показать его нельзя |

## Согласия пользователя

Если приложение работает там, где действует GDPR или CCPA, либо обращено к
детям, сообщите это до первой загрузки:

```kotlin
MorrisAds.setConsent(
    gdprApplies = true,
    gdprConsentString = tcfString,
    usPrivacy = ccpaString,
    coppa = false,
)
```

Без этого вызова каждая заявка утверждает, что GDPR не действует и аудитория не
детская. Если это не так, вызов обязателен.

## Рекламный идентификатор

SDK получает его самостоятельно. Если приложение уже запросило идентификатор для
другого SDK, передайте готовый — второго обращения к Google Play Services не
будет:

```kotlin
MorrisAds.setAdvertisingId(id, limitAdTracking)   // с фонового потока
```

При включённом ограничении отслеживания идентификатор не отправляется вовсе.

## Какие данные уходят

| | |
|---|---|
| Приложение | идентификатор пакета, версия |
| Устройство | производитель, модель, версия Android, размер и плотность экрана, ориентация, язык |
| Сеть | тип соединения, название оператора |
| Реклама | рекламный идентификатор и признак ограничения отслеживания |
| Согласия | то, что передано через `setConsent` |

Ни контакты, ни геопозиция, ни содержимое приложения не собираются и не
передаются.

## Разрешения

SDK объявляет их сам, добавлять в манифест ничего не нужно:

| Разрешение | Зачем |
|---|---|
| `INTERNET` | загрузка объявления и ролика |
| `ACCESS_NETWORK_STATE` | выбор файла под качество связи |
| `com.google.android.gms.permission.AD_ID` | рекламный идентификатор |

В форме безопасности данных Google Play объявите сбор рекламного идентификатора
и сведений об устройстве.

## Unity

Обёртка для Unity-игр — в каталоге [`unity/com.morris.ads`](unity/com.morris.ads).
Это мост к той же библиотеке, а не отдельная реализация.

## Сборка из исходников

```bash
./gradlew build                        # сборка и тесты
./gradlew :morris-sdk:assembleRelease  # AAR
```

Нужны JDK 17 и Android SDK (API 34). Тесты идут на JVM, устройство и эмулятор
для них не требуются.
